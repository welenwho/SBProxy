# TUN 接管与大陆白名单规则分流

SBProxy 仅保留 TUN 接管方式，继续保留大陆白名单、自定义路由、全局三种路由模式。
保留 URLTest、Tailscale 和入口接口绕过功能。`ip-full` 保留，增加
`kmod-nft-queue` 显式依赖。安装迁移删除旧 TProxy 配置字段，只清理能够确认属于
旧 SBProxy 实例的 TProxy 策略规则，不清空共享路由表，也不修改 Tailscale table 52。

## 大陆白名单分流组

入口是客户端设置的顶层“规则分流”Tab，与高级设置同级，仅大陆白名单模式生效。
分组编辑窗口按常规、域名、地址、端口和其他条件分为子 Tab。支持：

- 已启用的本地/远程规则集多选，以及内置中国 IP/域名规则集。
- 完整域名、域名后缀、关键词、正则；保留原来的快捷域名文本列表。
- IPv4/IPv6 目标与来源 IP/CIDR、私有地址匹配。
- 目标与来源端口、端口范围、TCP/UDP、IP 版本、协议及整体反向匹配。

匹配结构与自定义路由规则共用生成函数，使用 sing-box 默认规则语义，不能把每个
字段都看作独立 OR。例如域名和 443 端口同时配置时，端口仍是约束，不能让其他
域名的 443 流量误命中。空组、只有反向开关的空组不生成全匹配规则。
IPv6 匹配仍遵循客户端的全局 IPv6 开关，不会因新增 IPv6 条目而自动开启接管。

“规则集”管理 Tab 也向大陆白名单开放，但该模式只加载启用分组引用的自定义规则集。
缺失或禁用的引用报错，不忽略条件。该模式的远程规则集可选择直连或主节点下载，
与自定义路由已有的下载出站分开保存，避免切换模式破坏原有配置。

在客户端路由设置添加分流组，支持名称、启用、排序、域名列表和目标节点。
目标可以为直连、主节点（包括主 URLTest）或已有节点。分组以 UCI 列表保存，
不再把匿名 section ID 与外部文本文件绑定。节点失效默认报告配置错误，不擅自换出口；
用户也可明确选择回退主节点。
也可选择“仅拒绝该组流量”：引用的节点不存在时拒绝该组业务连接；纯域名组还会
返回 DNS REFUSED，连接/规则集条件组的 DNS 仍遵循既有策略。其余分组与 Tailscale
继续运行。此选项不是节点连通性探测；已有的默认
“报告配置错误”行为不变。指向主节点的分组复用主 DNS，不重复创建解析器。

有点的条目匹配域名后缀，无点的条目匹配关键词；转小写、去重并忽略 `#` 注释。
跨组重复、父子域、关键词重叠允许存在，会记录告警，按列表先后顺序匹配。
编辑窗口同时展示首个冲突及优先组，修改域名时更新提示。
设备/IP/MAC/入口绕过及端口限制优先于域名组；域名组优先于普通直连/代理名单和地理规则。
含关键词、正则、反向匹配或连接/规则集条件时，禁用可能抢先绕过的 GeoIP 快速路径，
待嗅探后按组顺序判断，避免复杂条件尚未判定就绕过分流组。

纯域名条件的组继续使用自己的 DNS detour，同一出站的多个组复用解析器；直连组用 WAN DNS。
包含规则集、IP、端口、来源条件、协议等连接条件的组只做业务分流，DNS 沿用既有策略。
这是为了避免把未来业务连接的目标端口/IP 误当成 DNS 查询的端口/IP，或删除这些
约束后错误地扩大 DNS 匹配。此类组不会自动创建全匹配 DNS 规则。
自定义路由和全局模式不加载这些组，原有规则、节点绑定接口和 DNS 配置保持独立。
这不是对现有自定义路由配置的自动转换。

## 统一地理资源

中国 IP 资源统一为 `geoip_cn.srs` 和 `geoip_cn.ver`，SRS 同时含 IPv4/IPv6。
仍保留 IPv6 开关，不是删除 IPv6 支持。
数据源改为 SagerNet/sing-geoip 的规则集分支（此前为 Loyalsoldier/surge-rules）；
因此除格式变化，也可能存在 IP 分类差异。域名资源仍使用 SagerNet/sing-geosite。

路由器下载后先用已安装核心反编译校验，安装失败恢复旧数据和版本文件。
CI 使用与 sing-box/Makefile 锁定版本一致、经过 SHA-256 校验的上游工具解析资源；
该工具仅用于校验，绝不替代包含本项目 Tailscale 补丁的路由器核心。
版本戳或规则编译顺序变化而匹配集合不变时，CI 保留现有内置文件，不提交，
也不递增插件修订号。

Hysteria v1 要求正数上下行带宽，缺少参数的订阅节点跳过；保留既有订阅失败保护。
Hysteria2 的可选带宽和拥塞控制不受影响。Naive 非 TCP 入站在界面中要求 TLS。

## 回归与升级提示

前端真实转换/回显函数通过 `tests/test-diversion-frontend.mjs` 验证，包含 `n/r` 字母、
LF/CRLF、多行、大小写、去重和一万条域名。此前版本若通过有转义缺陷的界面保存过
分组，需核对已保存域名；不能安全地自动推测被截断前的内容。
CI 校验工具缓存按版本和 SHA-256 分隔，每次命中仍验证压缩包，再解压到新临时目录。

扩展字段的界面绑定和保存由 `tests/test-diversion-fields-ui.mjs` 验证；
`tests/diversion-rule-fields.uc` 覆盖 IP-only、rule-set-only、组合条件、空条件、
无效引用及 DNS 边界。8.1 临时配置通过核心检查，自定义/全局生成结果与修改前一致。
